# Mukimies Homebrew tap

Homebrew casks for software published by Mukimies.

## EQ Ape

[EQ Ape](https://github.com/Mukimies/eq-ape) is a system-wide equalizer for macOS (14.2 or later, Apple Silicon) that reads Equalizer APO-style config files.

Install the current pre-release (0.1.0-beta.1, not notarized, so macOS will ask you to allow it under System Settings > Privacy & Security on first launch):

```sh
brew install --cask Mukimies/tap/eq-ape
```

Use the full name as shown. Current Homebrew refuses the short form (`eq-ape`) from a tap you have not explicitly trusted.
